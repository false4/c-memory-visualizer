# C 内存可视化（C Memory Visualizer）

一个纯前端的交互式 **C 语言内存可视化**教学工具：在浏览器里逐语句执行 C 代码，
把每个变量在 **栈区 / 堆区 / 全局（静态）区** 中的位置和大小实时画出来 ——
**内存块的高度与字节数成正比**，指针会画出指向目标的箭头，
`malloc` 申请的内存若在程序结束前没有 `free`，会以红色脉冲告警并生成泄漏报告。

## 功能

- **逐语句执行**：运行 / 暂停 / 单步 / 上一步 / 重置 / 速度调节，当前行高亮
- **内存分区可视化**
  - 栈区：函数调用栈帧（含递归），局部变量地址向低地址增长
  - 堆区：`malloc` / `calloc` 块，`free` 后变"墓碑"块（虚线、半透明）
  - 全局 / 静态区：全局变量 + 字符串常量池（rodata）
  - 块高度 ∝ 字节数（1 字节 = 8px），背景带字节刻度线
- **指针箭头**：SVG 曲线从指针变量连向它指向的变量 / 堆块；指向已释放内存时变红色虚线
- **安全检查与警告**
  - 内存泄漏检测（程序结束时汇总，列出每块的地址、大小、分配行号）
  - use-after-free、double free、堆 / 数组越界、空指针解引用
  - 除以 0、未定义变量 / 函数、死循环熔断（2 万步）
- **内置示例**：内存泄漏演示、基础类型与栈区、函数调用与栈帧、堆数组与指针运算、常见错误

## 支持的 C 语法子集

- 类型：`char / short / int / long / long long / float / double / unsigned`、多级指针、多维数组、字符串字面量
- 语句：声明与初始化、赋值（`= += -= *= /= %=`）、`if/else`、`while`、`do-while`、`for`、`break`、`continue`、`return`、函数定义与递归调用、`++/--`
- 表达式：算术 / 关系 / 逻辑（短路）/ 位运算、`&`、`*`、`[]`、指针运算、强制类型转换、`sizeof`
- 内存函数：`malloc` / `calloc` / `free`；内置 `printf`（`%d %c %f %s %p %x` 等）、`putchar`、`puts`
- 数据模型：64 位（指针 8 字节、`int` 4 字节），地址为教学演示用虚拟地址
- 暂不支持：`struct / union / enum`、函数指针、`realloc`、三元运算符、`switch`、`scanf`（跳过并提示）

## 技术栈

- React 19 + TypeScript + Vite + Tailwind CSS
- 自研 C 子集解释器（`src/lib/cvm/`）：
  - `lexer.ts` 词法分析 → `parser.ts` 递归下降语法分析 → `interp.ts` 基于虚拟内存模型的生成器式逐语句解释器
  - 每个执行步骤产出一份可序列化内存快照，前端按快照回放
- 快捷键：`空格` = 运行/暂停，`← / →` = 上一步/单步

## 本地运行

```bash
npm run build    # 构建到 dist/
```
